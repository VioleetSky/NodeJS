# Завдання 1: Aggregation Pipeline

## 1. Порахувати кількість товарів у кожній категорії

```js
{
    "_id": "$category",
    "totalItems": {
        "$sum": 1
    }
}
```

## 2. Порахувати середню ціну товарів по кожній категорії

```js
{
    "_id": "$category",
    "averagePrice": {
        "$avg": "$price"
    }
}
```

## 3. Знайти сумарну вартість складу — суму price * stock по всіх товарах

```js
{
    "_id": null,
    "totalStockValue": {
        "$sum": {
            "$multiply": [
                "$price",
                "$stock"
            ]
        }
    }
}
```

## 4. Вивести тільки ті категорії, у яких середня ціна більша за 300

### Stage 1 — `$group`

```js
{
    "_id": "$category",
    "averagePrice": {
        "$avg": "$price"
    }
}
```

### Stage 2 — `$match`

```js
{
    "averagePrice": {
        "$gt": 300
    }
}
```

## 5. Порахувати кількість активних та неактивних користувачів

```js
{
    "_id": "$isActive",
    "totalUsers": {
        "$sum": 1
    }
}
```

# Завдання 2: Індекси та швидкість запитів

## 1. Дізнайтеся, що таке індекс у MongoDB, як він влаштований і чому прискорює пошук

* **IXSCAN** — пошук за допомогою індексів, що прискорює виконання запитів.
* **COLLSCAN** — пошук без індексів по всьому масиву даних, що значно сповільнює виконання запитів.
* **індекс** — заздалегідь відсортована одного конкретного поля.

---

## 2. Виконайте `db.products.getIndexes()` та `db.users.getIndexes()`
